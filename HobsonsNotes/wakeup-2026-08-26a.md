### Database migration runner

Dan built `DbMigration/Migrator/` — standalone F# console app, outside
`Src/`. Interactive-only: menu selects environment, password typed each
run (masked input). No env vars, no stored credentials. All three
environments rebuilt from scratch via migration chain.

Key details:
- SQL files in `DbMigration/Scripts/` (Dan reorganized from flat
  `DbMigration/*.sql`)
- `{ENV}` token in SQL is interpolated to `dev`/`test`/`prod` at runtime
- Tracking database: `sonofleo_migration` with `migration.dml` and
  `migration.history` tables
- `sonofleo_migrator` role: has `CREATE` on all three databases, member
  of each app role for ownership transfer
- CreateDatabase migration is always manual (need the database to exist
  before connecting)
- Pen tested: PTY can bypass interactive console, but password is the
  real gate. Migrator password is not in any env var, config, or file
  accessible to agents. BD's container has network isolation from prod.
