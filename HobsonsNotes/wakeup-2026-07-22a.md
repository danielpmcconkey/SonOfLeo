### The refactor (what changed since wakeup-2026-07-11a)

This is the biggest structural change since the project started. The headlines:

1. **AppError DU** (`Src/Utilities/AppError.fs`) — replaced `Result<_, string>`
   everywhere with `Result<_, AppError>`. Typed, structured errors with contextual
   data. Formatting deferred to `AppError.toMessage` at the CLI boundary.

2. **InterfaceBridge project** (`Src/InterfaceBridge/`) — new project acting as
   MVC-style middleware between Model and CLI. Contains:
   - `BoundaryConverters/` — typed converters between interface primitives and
     domain types (the `convert X to Y` functions with backtick names)
   - `InterfaceContracts/` — `*Input` and `*Return` DTOs (moved from Model/UI)
   - `Routes/` — route handlers (moved from SonOfLeoCli)
   - `CommandRoute.fs`, `Json.fs`

3. **Model purified** — all model entry points now accept fully validated domain
   types, never primitives. Parsing happens at the InterfaceBridge boundary.

4. **Entity ID wrappers** — `AccountId`, `FiscalPeriodId`, `JournalEntryHeaderId`,
   `JournalEntryLineId`, etc. No more raw Guids flowing through domain code.

5. **Creation functions graduated to orchestration** — `AccountCreation`,
   `FiscalPeriodCreation`, and all JE component orchestration files now live in
   ModelOrchestrator. Model `create` functions are pure assembly (no validation,
   no Result).

6. **JournalEntryPrimitives eliminated** — no more intermediary types. JE creation
   takes tuples of domain types directly.

7. **VTC pattern retired** — replaced by: `create` (pure assembly from domain
   types), `reconstitute` (from DB, type-level validation only), orchestrated
   `constructNewAndSaveToDb` (state validation at write time). Several
   CompoundedLearnings articles will need updating.

8. **Split-query fetch pattern** — JournalEntry fetching uses batched queries
   (one per component table with IN clauses) instead of a wide Cartesian join.
   Sorting done in-memory via `List.sortBy`/`List.sortByDescending`.

9. **DevDataStage moved** — out of `Src/` to repo root. Action item #116a done.

10. **FieldUpdate module** (`Src/Utilities/FieldUpdate.fs`) — DU definition +
    map/traverse helpers for both option and non-option variants.

11. **ResultHelper consolidated** — `ResultCE.fs` and `ListHelper.fs` merged into
    `ResultHelper.fs`. `convertOptionToDesiredTypeWithFallibleConverter` moved here
    from InterfaceBridge.

12. **Clock.now switched to pure NodaTime** — `SystemClock.Instance.GetCurrentInstant()`
    with microsecond truncation preserved.
