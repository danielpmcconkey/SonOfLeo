### Staging Domain Charter

Design session produced `HobsonsNotes/staging-domain-charter.md` — L1/L2
breakdown of the staging/import domain. Nine components: base staging
format, ingestion CLI, vendor classification rules engine, classification
pass, manual classification, dedup, shadow post, batch post, bespoke FI
parsers. Phased A–E.

Key design decisions from the session:
- **Classify after staging, not before.** Stage the raw rows first; run
  classification as a separate pass over staged rows.
- **Shadow post is the game-changer.** Trial balance delta before
  committing eliminates the void-and-repost cycle.
- **Bespoke parsers stay outside SonOfLeo.** SonOfLeo's boundary is
  "a valid base-staging-format file appeared."
- **Ledger transactions only.** Portfolio/positions are a separate domain.
- **Trial balance ≠ new engine.** It's FetchBalances with no account
  filter + tree roll-up + optional HTML rendering.
