## What happened this session

### Agentic pipeline plan written

Dan and Hobson designed a seven-layer development pipeline:

1. **Layers 1–4** — conversational (Dan + agents in Claude Code):
   strategy/spec, technical architecture, test planning, plan audit.
2. **Layer 5** — autonomous build pipeline: a Python state machine in
   the SonOfLeo repo (`Pipeline/`) driving cards through a Postgres
   kanban. Fresh Claude CLI agents (builder, test agent, code reviewer,
   foreman) process each card. Dependency-aware card selection, blocker
   protocol, configurable daily budget for session limit management.
3. **Layer 6** — Hobson-led SIT: Hobson runs Checks + audit, adjudicates
   first-round findings, assigns remediation to Simian/BD/self. Only
   unresolved items bubble to Dan.
4. **Layer 7** — Dan merges to main.

Key design decisions:
- State machine lives in SonOfLeo, not Nightshift. Domain knowledge
  (SrcDeveloper skill, CRUD shape, CompoundedLearnings) is too specific
  for DSWF addenda.
- Artifact-driven: Postgres for state, files for agent artifacts.
- Single release branch per slice, sequential commits, no per-card
  branching.
- Hobson gains first-round audit adjudication authority (Layer 6.3) —
  a new lane expansion.

The full plan is at `HobsonsNotes/agentic-pipeline-plan-2026-09-13.md`.
