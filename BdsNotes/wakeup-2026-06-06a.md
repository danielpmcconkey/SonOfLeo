## Concepts Dan solidified

- **Result.bind / Result.map** — used fluently now, understands the
  difference (bind for functions returning Result, map for plain transforms).
- **Computation expressions** — `result { let! / return! }` as sugar for
  nested binds. Wrote the manual version first, then refactored.
- **Discriminated unions as type carriers** — QueryParameterValue DU
  replaced Object + separate ColumnType. Understands why.
- **try/with + use** — .NET boundary pattern: catch exceptions, convert
  to Result, use for IDisposable. Understands this isn't a railway
  breakdown, it's the railway acknowledging side effects.
- **Option.ofObj** — null → Option conversion at .NET boundaries.
- **Private records** — understands the trade-off (construction protection
  vs accessor boilerplate). Correctly identified the "Java getter" smell
  and accepted the cost.
- **`|> function`** — shorthand for piping into a match expression.
