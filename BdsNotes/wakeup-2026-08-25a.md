outside a transaction, and its safety is entirely the `finally`. If that ever fails to run it
leaves a second account holding `F-1250` and the account suite stays red until someone deletes
the row by hand. The two `REQ-CR-1.22` tests have the same shape and the same exposure.

`CompoundedLearnings/articles/testing/mutation-proves-liveness-not-aim.md`.

## Environment

- Read first: `README.md`, then `Tests/README.md`. `Skills/TestWriter/SKILL.md` is the
  procedure and its three-phase workflow is not optional.
- Builds **must** pass `--artifacts-path /tmp/sonofleo-build`. A bare `dotnet build` in this
  bind-mounted repo fills Rider with container paths.
- Connection strings are `SONOFLEO_TEST_CONNSTR` / `SONOFLEO_DEV_CONNSTR`, in Npgsql format —
  `psql` will not take one directly, parse it into `PG*` vars. Never echo either.
- `git-guard` rejects every git subcommand that can overwrite the working tree. Use
  `git switch`; put a file back by copying from a backup, never by asking git. It greps the
  whole command text, so **it also rejects a heredoc that merely names one of those verbs** —
  writing this file cost two attempts to that, once for describing the hook and once for
  describing how to work around it. Say "put back", not the verb.
- `Checks/check-traceability.sh` exits 0 on any branch that is not `main`, so its PASS inside
  `run-all.sh` means nothing here. Run `traceability-audit.sh .` directly.
- `check-hardwired-dates` rejects near-present dates in integrated tests. The leap-year cases
  use 2048 and 2050 for that reason.
