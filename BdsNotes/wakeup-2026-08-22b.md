  Write prose files with the Write tool rather than `cat` when they discuss git.

  `Checks/../.claude/hooks/git-guard.py` blocks `switch` only with `-f` / `--force` /
  `--discard-changes`. Earlier wakeups called the whole branch-switching family blocked. They
  were wrong.
- **Never restore a file with `mv` from a backup.** `cp` then `touch` — `mv` preserves mtime,
  MSBuild skips the rebuild, and you get a green run of stale code.
