**CLI architecture (complete):**
- Renamed UiPrimitives to InterfaceContractTypes — per-use-case input types
  (AccountCreateInput, AccountDeactivationInput, etc.) with shared AccountReturn
  output type. Interface contracts, not domain mirrors.
- Model.UI.Json: generic `fromJson<'T>` / `toJson<'T>` with NodaTime + F# option
  converters. Centralized marshalling for all front doors.
- Data-driven route table: `CommandRoute` records with domain, verb, description,
  input/output type names, and handler function. `route` does a `List.tryFind`
  lookup — no nested match statements, no touching the router for new commands.
- AccountRoutes module: 9 handlers — create, deactivate, updateName,
  updateExternalReference, fetchById, fetchByCode, fetchByParentId,
  fetchByAccountType, fetchAll. Shared `convertAccountToAccountReturn` helper.

- `fetchAll` takes `activeOnly: bool`, uses `Clock.now()` internally.
