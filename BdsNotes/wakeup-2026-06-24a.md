**Architecture — Type Validation Doctrine (Specs/Conventions/Doctrines.md):**

- Typed error DUs instead of Result<_, string> (not yet implemented — do this before building more JE code).
- Validation layers: type definitions → validateThenConstruct → composite validation → operation functions.
- Persistence gate: nothing persisted, reconstituted, or returned to UI without passing through validateThenConstruct.
