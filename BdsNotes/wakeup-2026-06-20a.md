**Fiscal Period slice (in progress):**
- Wrote FiscalPeriodCrud.md spec. Key design decisions:
  - Periods are calendar months only. Key format is `YYYY-MM`.
  - Start/end dates are derived from the key, not caller-provided.
  - No nesting — roll-ups to quarters/years are a reporting concern.
  - JE entry dates are Dates (LocalDate), not Instants. GAAP doesn't care
    about time-of-day for transaction recognition.
  - Open/closed state is a bare boolean flip — no closing machinery, no
    audit trail, no pre-close validation. Deferred per Hobson's guidance.
- Created PeriodKey value type with regex validation `^\d{4}-(0[1-9]|1[0-2])$`.
- Created FiscalPeriod domain type with reconstitute, constructNew,
  insertNewToDb, and constructNewAndSaveToDb.
- Added DbLocalDate and Boolean to DAL QueryParameterValue DU.
- Created DB migration for ledger.fiscal_period table.
