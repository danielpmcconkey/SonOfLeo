**CLI architecture decided:**
- stdin JSON is the input strategy. Args are `domain verb [rest...]` for
  routing, stdin carries the payload.
- `Model.UI.UiPrimitives` holds dumb primitives records (one per entity).
  `AccountPrimitives` is the first — all fields are primitives/NodaTime,
  id and audit dates are options so one type serves both input and output.
- `Model.UI.Json` provides generic `fromJson<'T>` / `toJson<'T>` with
  NodaTime Instant and F# option converters. Centralized so N front doors
  share one serializer config.
- UI layer owns both conversions: JSON→primitives on input,
  domain→primitives→JSON on output. Model.UI never touches domain types,
  domain never touches JSON.

**Program.fs — first end-to-end command:**
- `main` reads stdin, destructures argv into `domain :: verb :: rest`,
  routes to handler.
- `accountCreate` deserializes stdin to `AccountPrimitives`, unpacks into
  `Account.constructNewAndSaveToDb`, maps the returned `Account` back to
  `AccountPrimitives`, serializes to JSON stdout.
- `route` returns `Result<string, string>` — main forks on Ok (stdout, exit 0)
  vs Error (stderr, exit 1).

**Removed redundant `System.Text.Json` PackageReference** — .NET 10 bundles it.

**F# learning moments:**
- Generic function syntax: `let fromJson<'T> (json: string) : Result<'T, string>`
- `typeof<'T>` (no space) for type name in interpolated strings
- `Option.map` on `None` returns `None` — safe unwrap through options
- List destructuring: `first :: second :: rest` binds head elements, rest is the tail
- `printfn "%s"` is type-checked at compile time (F#'s format specifiers)
- `eprintfn` for stderr
- `open` (import) vs `<PackageReference>` (NuGet) — removing the package
  doesn't remove the namespace, .NET bundles common packages
